# 首次連線：先讀取，確認後再寫入

這是尚待實體裝置驗證的開發版，不是 WCH 官方工具。首次測試請使用可回復的環境，不要先對重要、正在運行的設備做出廠還原。

## 安裝與開啟

將自己確認來源的 `CH9121 Config.app` 放到 Applications。此版本只有 ad-hoc 簽署，未經 Apple 公證；若系統阻擋，使用「系統設定 → 隱私權與安全性」針對這個 App 的個別允許開啟選項。不同 macOS 版本的提示可能略有差異。不要關閉全域 Gatekeeper，也不要移除整個 Downloads 的隔離標記。

第一次搜尋時，若 macOS 詢問區域網路權限，請允許。被拒絕時可在系統設定的區域網路權限中檢查。

## 接線與讀取

1. 使用穩定供電，接到已確認能讓模組正常運作的 switch 或電腦 Ethernet。先不要把這個程式當作 switch 重啟問題的修復方法。
2. 關閉原廠 NetModuleConfig 或另一份本程式；UDP 60000 同時間只給一個設定工具使用。
3. 選實際連到模組的 Ethernet 網卡，以顯示的 IPv4 和 MAC 協助辨認，不要假設一定是 en0。按「搜尋設備」。
4. 核對目標 MAC，雙擊設備或按「讀取設定」，先按「儲存設定」保存 JSON。
5. 沒找到時先檢查網卡、區域網路權限、防火牆、供電、VLAN／訪客隔離，不要直接恢復出廠。

搜尋設定透過同一區域網路的 UDP 廣播；實際雷達接收仍須按手冊設置相容的 IP／遮罩。若模組是 192.168.1.200/24，電腦例如可設未被占用的 192.168.1.102/24；這只是手冊示例，請先確認你的網路，程式不會自動修改 Mac 的 IP。

## M10P

讀取後選 M10P，確認接收 IP 是真正要接收雷達資料的電腦，按「填入預設」。這只改畫面，不會傳送設定。

核對 UART1：UDP CLIENT；本地埠 2369；目的埠 2368；baud 512000；資料位 8；停止位 1；無校驗。設備 IP、遮罩、閘道與 UART2 不會被套用預設改掉。

按「寫入設定」，檢查確認框中的目標 MAC 和差異。程式先保存自動備份、重新讀取排除外部修改，送出一次寫入，再等待重新 GET 核對。若顯示「結果未確認」，請重新搜尋／讀取，不要反覆按寫入。

## 首次硬體驗證紀錄

請逐步確認搜尋、讀取、名稱小幅修改後讀回、參數備份／載入、雷達 UDP 接收。實體驗證至少記錄晶片字樣、韌體版本、網卡名稱、macOS 版本、讀回差異及必要時的 HEX 通訊紀錄。

通訊紀錄可能包含你的裝置 MAC、內網 IP 和設定；分享前先檢查。備份只存在本機，不會自動傳到 GitHub。

「恢復出廠設定」是破壞性操作，會讓 M10P 的通訊參數失效，通常不應是首次測試步驟。
